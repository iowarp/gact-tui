# @clio/core

Shared TypeScript client for the GACT v0.2 contract. Consumed by `@clio/web`
and `@clio/desktop`. No DOM dependencies — pure logic, types, and a fetch-based
HTTP client.

This is the harness scaffold. Full coverage of the contract (workspaces, MCP,
permissions, files, agents, metrics) is tracked in `apps/PLAN.md`.
