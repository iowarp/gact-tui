# Draco decoder assets

These three decoder files are copied from `three@0.180.0/examples/jsm/libs/draco/` for the generic 3D viewport. They are the Draco project’s browser decoder builds, distributed under the [Apache License 2.0](https://github.com/google/draco/blob/master/LICENSE). The upstream source is [google/draco](https://github.com/google/draco).
