How it works
Open and close the left and right pockets?
CtrlB⌘B

CtrlShiftB⇧⌘B
Both are on develop already. Ctrl B⌘B is the left pocket, Ctrl Shift B⇧⌘B the right. The right one comes back at the width you left it.
The right pocket is open. How do I get a terminal?
Ctrl`⌃`

CtrlShift`⌃⇧`
Ctrl `⌃` goes to your last terminal. With none open it starts one, and with the pocket closed it opens it. Ctrl Shift `⌃⇧` always starts a new one. Same keys as VS Code, which also uses ⌃ here on a Mac.
Do I have to press Ctrl⌘ to see them?
hold CtrlorCtrl/hold ⌘or⌘/
Hold Ctrl⌘ for half a second and every control that has a key shows it, like the screenshot above. Let go and they're gone. Hovering shows the same key in the tooltip, and Ctrl /⌘/ opens the full list.
What opens the ⋯ menu from the keyboard?
ShiftF10orMenu⌃↩

Alt↓⌥↓
Shift F10⌃↩ opens the menu of whatever has focus: the tab's ⋯, a row's actions, a selection's actions. The conversation's ⋯ in the title bar has its own key, Alt .⌥⌘., since focus is usually in the composer. On a split button, Alt ↓⌥↓ opens its chevron.
If I clicked ⋯ with the mouse, pressing L makes no sense?
CtrlShiftL⇧⌘L
Right, so menus stop showing letters. The right column shows the key that works from anywhere, without opening the menu. Letters still jump inside an open menu, but they're underlined only when you opened it from the keyboard.
How do I get to Lineage from the Source view?
CtrlShiftL⇧⌘L
It's the third icon in the toggle, after Render and Source. Hover shows "Lineage, Ctrl Shift L⇧⌘L". The maximized tab has the same bar, so it works the same there.

Rules
One key, four places. The tooltip, the menu's right column, the held-key badge and Ctrl /⌘/ all show the same key. Change it once and all four follow.
⌘ on a Mac, everywhere. Each key is written once, for Windows. The Mac form is derived from it: Ctrl becomes ⌘, Alt becomes ⌥, ↵ becomes ↩ and Delete ⌫, in Apple's order ⌃⌥⇧⌘. Only the exceptions below are written by hand.
Two scopes. "Anywhere" keys work from any focus. "The tab you're in" keys work when focus is in the right pocket, so Ctrl Shift L⇧⌘L never fires from the composer.
Positions, not letters, for lists that grow. The strip and the mode toggle number by position, so a new strip icon or renderer gets a key for free.
Keys the browser and the OS keep. Ctrl N, T, W, Tab, L, 1–9, PgUp, PgDn, F5, and Ctrl Shift N, T, W, I, J, C.⌘Q, H, M, N, T, W, L, Tab, `, Space, 1–9, ⇧⌘3, 4, 5, ⌥⌘M, ⌥⌘I, J, C, U, and ⌃Space, ⌃←→↑↓. Nothing uses them. That's why New conversation is Ctrl Shift O⇧⌘O in a browser.
Text fields win. Inside the composer or a Source editor, typing keys (Ctrl C⌘C, Shift ↵⇧↩, letters) do what they do in text. On a Mac that also rules out bare ⌥ chords there, since ⌥ types characters.

Open questions
  • New conversation in a browser. Ctrl Shift O (⇧⌘O), like ChatGPT? It takes over Chrome's bookmark manager key.
  • Hold the key. Is half a second right?
  • Strip by number or by letter. Numbers never clash and grow with the strip. Letters are easier to remember, but most of them are already taken by browsers.
  • Esc in the composer. Stop the run, or only clear focus?
  • Mac browser build. Chrome on a Mac may act on ⌘, (its own settings) and ⇧⌘/ (its Help menu) before the page sees them. The desktop app is fine. I haven't tested Safari.
