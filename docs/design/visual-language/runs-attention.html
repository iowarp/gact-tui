Open questions
  • Runs page. The middle column, as drawn, or a tab in the right pocket?
  • Retry. Develop can only cancel. Rerun the same step, or ask the agent?
  • Running order. One list ordered by need, as drawn, or v23's Needs you, Now and Done labels?
  • Double alerts. A waiting run shows on the rail button and the bell. Bell only for other conversations?
  • Ctrl Alt N⌥⌘N. Ctrl Alt is AltGr on some layouts (Polish AltGr N types ń). Same risk as v22's Ctrl Alt M⌥⌘A.
  • Science log Source. Show the raw log, or no Source?
  • Big vaults. One graph for 6 nodes and 600 notes, or a dot style for big graphs?
  • Words. "Form" for A2UI surface, "heat profile" for attention profile?
