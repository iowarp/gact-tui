# Interface languages

The Web and Desktop interface is translated with [Lingui](https://lingui.dev).
Copy is written in English where it is used, wrapped in a translation macro, and
`pnpm --filter @clio/workspace i18n:extract` collects it into one PO catalog per
language under `web/src/locales/<locale>/messages.po`.

Languages: English (source), Spanish, Japanese and Greek, plus a development-only
pseudo-locale (`⟦Ŝéttîñgš····⟧`) that makes untranslated copy and clipped layouts
easy to spot.

## How it works

- `web/src/i18n/instance.ts` is the one translation instance. It starts active in
  English with no catalog: every macro call carries its English message, so any
  page, review fixture or test renders English without loading anything.
- `web/src/main.tsx` resolves the language (`?locale=` in the URL, else the stored
  choice, else the system languages), loads that catalog, and only then imports the
  application. Copy computed when a module loads is therefore already translated.
- Changing the language in **Settings → Appearance → Language** stores the choice
  and reloads the window. Nothing has to re-render on a language change, so `t`
  may be used anywhere: in components, hooks, plain modules and module-level
  constants.
- `<html lang dir>` follows the active language.
- `?locale=pseudo` (or `?locale=es`) opens any page in that language without
  changing the stored choice. Review screenshots use it.

## Writing copy

```ts
import { plural, ph, t } from '@lingui/core/macro';
import { Trans } from '@lingui/react/macro';

title={t`Conversation width`}
toast.error(t`Could not open ${fileName}`);
label: plural(count, { one: '# file', other: '# files' }),
<Trans>Saved to <code>{path}</code></Trans>
```

- **`t`** for any string: a JSX attribute, a value in an object, a toast, an
  `aria-label`. It returns a plain `string`.
- **`<Trans>`** only when the message contains elements (`<code>`, `<strong>`, a
  link). Plain JSX text is `{t\`…\`}`.
- **`plural` / `select`** for anything that depends on a count or a category. Never
  build plurals with `count === 1 ? 'file' : 'files'` or `+ 's'`: Spanish, Greek and
  Japanese do not inflect like English.
- **Whole sentences.** A message is the full sentence with placeholders, never
  pieces concatenated together: word order differs between languages.

  ```ts
  // Wrong: three messages, fixed English order
  t`Copied` + ': ' + name;
  // Right
  t`Copied: ${name}`;
  ```

- **Name placeholders.** `${name}` becomes `{name}` for the translator. A member
  expression or call becomes `{0}`; name it with `ph`:
  `t\`Saved version ${ph({ version: artifact.version })}\``.
- **Context for ambiguous words.** A short label that could be a verb or a noun
  gets a context: `t({ message: 'Open', context: 'verb' })`.
- **Brand words** come from `@/lib/brand-vocabulary` as placeholders:
  `const { agent } = vocab; t\`Keep ${agent} running?\``. Do not compose articles or
capitalization in code (`withArticle`, `capitalize`): write the whole phrase.
- **Dates and numbers** go through `@/lib/locale-format`, which formats in the
  active language. Do not call `toLocaleString()` with a hard-coded locale.

## What is not translated

- What the agent or a tool produced: conversation text, A2UI surfaces, file
  contents, tool names and arguments, JSON in Technical details.
- Text sent to the agent or a server as an instruction or identifier (prompts the
  interface composes for the model, validation messages returned to the agent,
  protocol values, keys, ids, file names). Keep these in English.
- Language names in the language picker (each is written in its own language).
- Developer output: `console.*`, thrown `Error` messages that are not shown as
  interface copy, test ids.
- `web/src/theme/`: it is bundled into the pre-paint boot script without the
  translation runtime. Theme names are translated where they are shown.
- Modules imported by `web/src/lib/onboarding/install-snapshot.ts`, which runs
  before the language is active.

A string the copy lint flags that is not interface copy gets an `i18n-ignore`
comment with the reason, on its line or the line above:

```ts
// i18n-ignore: protocol name, identical in every language
const PROTOCOL_LABEL = 'GACT protocol';
```

## Values that are both an identifier and copy

When a string is compared, stored or used as a type (`type Stage = 'Checking…'`),
keep a stable identifier and translate at display:

```ts
type Stage = 'checking' | 'finding-models';
const STAGE_LABELS: Record<Stage, string> = { checking: t`Checking…`, … };
```

## Desktop host and brand

- The desktop host's own strings (macOS menu bar, tray, the macOS "Move to
  Applications" prompt) are messages in `web/src/tauri/native-copy.ts`. After the
  language is active the interface sends them, translated, to the host
  (`set_native_copy` in `desktop/src-tauri/src/native_copy.rs`), which relabels its
  menus and saves the table so the next launch starts in that language. The keys
  and English text are defined in both files; tests on each side fail when they
  drift apart.
- Menu items macOS adds itself (Close All, AutoFill, Emoji & Symbols, Window ›
  Fill) come from AppKit. The bundle declares the interface languages
  (`CFBundleLocalizations` in `desktop/src-tauri/Info.plist`), and when the person
  picks a language the host writes it to the app's `AppleLanguages` default
  (`desktop/src-tauri/src/app_language.rs`), so those items follow from the next
  launch. Choosing System removes it again, unless it has since been changed in
  macOS's own per-app language setting. A new interface language is added to
  `Info.plist` and `app_language.rs` too; a test checks all three lists agree.
- Errors the host returns to the interface are still English sentences; they are
  shown as they arrive.
- A brand's own words (landing copy, greeting, tagline) come from its
  `brand.json`, with other languages under `locales`; see
  [branding/README.md](../branding/README.md). The `@brand` module applies the
  active language when it loads.

## Checks

- `node scripts/check_unlocalized_copy.mjs` (part of `pnpm lint`) fails when a file
  has more untranslated copy than `scripts/unlocalized_copy_baseline.json` records.
  The baseline is empty, so any new bare string fails. `--list <path>` shows each
  string, `--summary` counts by directory.

  It reads the syntax tree and reports: JSX text; copy-shaped JSX attributes (also
  through nested conditionals); prose strings; template strings with words
  (`${n} files`, `Removed ${name}`); one-word values of label properties
  (`label: 'move'`); tables of capitalized labels; capitalized words returned from
  `…Label` or display `…Name` functions (`workspaceName`), rendered as JSX children
  or passed to a local `label`
  parameter. It is a heuristic: it cannot see text a third-party component
  supplies itself, or a value named like data (`value: 'Direct'`).

- `pnpm --filter @clio/workspace i18n:extract` updates the catalogs. Commit the
  catalogs with the change that adds or edits copy; `check_i18n_catalogs.mjs` fails
  when they are stale or a translation loses a placeholder or does not compile.
- Open the screens you changed in the pseudo-locale (`?locale=pseudo`), including
  their menus and dialogs: interface text without `⟦ ⟧` is untranslated. It is
  also about 30% longer than English, like German, so check layout at desktop and
  phone widths.
- Library components can carry their own English: name them through their props
  (`Toaster` `containerAriaLabel`, cmdk `CommandList` `label`, the calendar's
  `locale`). The shared wrappers in `components/ui` already do.

## Known limits

- A "Reference this" block describes its zone in the interface language, since the
  person attaches it to their own message; the filter lines in the same block stay
  English, as does the query JSON.

- A few labels are lowercased to sit mid-sentence ("No {facet} in the listed
  models"). That is right for Spanish, Greek and Japanese; a language that
  capitalizes nouns (German) would need those as whole messages.
- Tool rows show an action and its target side by side ("Wait for" + tasks), as
  two parts of one row rather than one sentence.
- Settings search also matches the English keywords, so English search terms
  keep working in every language.
- Errors the desktop host or the agent service return are shown as they arrive,
  in English.
- Compact durations ("5m 3s") use English unit letters.
- The offline archive viewer embedded in exported conversations is in English:
  bundling every catalog into each archive would make archives much larger.

## Translating

Each PO catalog is plain text that translation tools (Weblate, Crowdin, Poedit)
read. Spanish, Japanese and Greek were machine-translated; `machineTranslated` in
`web/src/i18n/locales.ts` records that, and the Language setting tells the reader.
When a speaker has reviewed a catalog, set it to `false`.

Keep placeholders (`{name}`, `{0}`), ICU syntax (`{count, plural, one {…} other
{…}}`) and element tags (`<0>…</0>`) intact; translate only the words around them.
