This release finishes the interface introduced in 0.12.0 and makes it available in
Spanish, Japanese and Greek. It ships with CLIO 0.9.7.

### In your language
The interface, the Desktop menus and tray, Desktop errors and the update reason are
available in English, Spanish, Japanese and Greek. Choose the language in Settings >
Appearance > Language, or follow the system. The translations are machine-made and
marked as such until a native speaker reviews them.
([#1232](https://github.com/iowarp/gact-tui/pull/1232), [#1237](https://github.com/iowarp/gact-tui/pull/1237), [#1241](https://github.com/iowarp/gact-tui/pull/1241), [#1242](https://github.com/iowarp/gact-tui/pull/1242), [#1243](https://github.com/iowarp/gact-tui/pull/1243), [#1244](https://github.com/iowarp/gact-tui/pull/1244))

### See what a script did
A script's tool row shows what the script ran, the images it viewed and whether the
model saw them. Show the task in Work opens the run, and Open in tab shows its printed
output in full.
([#1229](https://github.com/iowarp/gact-tui/pull/1229))

### Web search and model settings
Settings > Web search orders CLIO's built-in web and literature sources, turns each on
or off and holds their keys; the SearXNG screens are gone. Settings > Models offers a
fast model, which helpers use unless given their own, and a Delegation section for the
accounts that may run delegated work.
([#1234](https://github.com/iowarp/gact-tui/pull/1234), [#1226](https://github.com/iowarp/gact-tui/pull/1226))

### See what tools and agents carry
An MCP server's tools use the same rows as built-in tools, with their permissions, and
every tool opens its details. The agent view shows the agent's packages and prompt,
and its subagents and skills open on their own pages.
([#1227](https://github.com/iowarp/gact-tui/pull/1227), [#1228](https://github.com/iowarp/gact-tui/pull/1228))

### A tour for new users
A short guided tour starts on first launch. Replay it from Settings > General.
([#1155](https://github.com/iowarp/gact-tui/pull/1155), [#1214](https://github.com/iowarp/gact-tui/pull/1214))

### Transcript and workbench
The conversation rail docks beside the transcript while the side pocket is closed,
and its rows show New activity for conversations that aren't open. Switching
conversations keeps the window in place. The lineage graph is laid out with fewer
crossing lines and supports zoom, pan and drag. A PDF cited by the agent opens on the
cited page, and a comment marked on an older version of a file offers to mark it again
on the current one. Interface size scales every piece of text.
([#1203](https://github.com/iowarp/gact-tui/pull/1203), [#1209](https://github.com/iowarp/gact-tui/pull/1209), [#1190](https://github.com/iowarp/gact-tui/pull/1190), [#1207](https://github.com/iowarp/gact-tui/pull/1207), [#1179](https://github.com/iowarp/gact-tui/pull/1179), [#1212](https://github.com/iowarp/gact-tui/pull/1212), [#1217](https://github.com/iowarp/gact-tui/pull/1217))

## Fixed

- A reply that failed after partial output offers Retry. ([#1180](https://github.com/iowarp/gact-tui/pull/1180))
- A draft moved to another workspace keeps its model, agent and text. ([#1223](https://github.com/iowarp/gact-tui/pull/1223))
- Deleting a conversation or workspace that still has running work says why it can't
  be deleted yet, instead of "409 Conflict". ([#1216](https://github.com/iowarp/gact-tui/pull/1216))
- Workspace rows open their menu on right-click. ([#1205](https://github.com/iowarp/gact-tui/pull/1205))
- Focus returns to the search question after choosing its model, and Ctrl K Esc steps
  back from a typed prefix. ([#1188](https://github.com/iowarp/gact-tui/pull/1188), [#1231](https://github.com/iowarp/gact-tui/pull/1231))

## Known issues

- In Greek and Japanese, some labels are cut off at desktop width: the CLIO menu,
  Infrastructure map nodes, some Settings rows and the shortcut sheet.
- Settings > Runtime and history is still in English in Greek and Japanese.
- Bell request rows can show a raw "destructive tool call:" title.

These will be fixed in a patch release.
