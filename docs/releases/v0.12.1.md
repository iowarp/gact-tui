This release fixes the 0.12.0 interface.

### The Browser is yours again
A new conversation's Browser tab has a New page row and an address field again.
Open a page, search or sign in yourself, then ask the agent to use the page
that is open.
([#1137](https://github.com/iowarp/gact-tui/pull/1137))

### New terminals and pages from the icon strip
Each press of Terminal or Browser in the workbench icon strip opens a new
terminal or a new browser page, replacing the old "+" button. Right-click
either icon for the list of open ones. Typing an address in a New page tab
opens the page in that same tab.
([#1138](https://github.com/iowarp/gact-tui/pull/1138),
[#1140](https://github.com/iowarp/gact-tui/pull/1140),
[#1142](https://github.com/iowarp/gact-tui/pull/1142))

### Pinned comments on browser pages
Comments on a browser page now show as pins on the page, like comments in other
tabs. They come back after a reload or after navigating back, stay on their
spot when the page layout shifts, and a comment whose mark is no longer on the
page says so.
([#1139](https://github.com/iowarp/gact-tui/pull/1139),
[#1141](https://github.com/iowarp/gact-tui/pull/1141))

## Fixed

- Opening or switching workbench tabs no longer resizes the right pocket; only
  dragging its edge or resizing the window changes its width.
  ([#1136](https://github.com/iowarp/gact-tui/pull/1136))
- The desktop app no longer shows doubled native scrollbars.
  ([#1134](https://github.com/iowarp/gact-tui/pull/1134))
- Styles the desktop app's content security policy blocked apply again, and the
  workbench no longer overflows by one pixel.
  ([#1135](https://github.com/iowarp/gact-tui/pull/1135))

See the [CHANGELOG](https://github.com/iowarp/gact-tui/blob/main/CHANGELOG.md#0121---2026-11-11).
