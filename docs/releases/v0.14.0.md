This release brings connectors, apps and science views into the interface. It ships with CLIO 0.9.8.

### Connectors and apps in the conversation
Turn connectors on per conversation and find new ones in Discover. A connector's live view (an MCP App) opens in the conversation, in its own tab or in a dashboard beside other results, including the CAD viewer and the KiCad board.

### Maps, sections and profiles
A layered map shows grids, points, tracks and shapes on one time axis, with shapes coloured by category. New views draw sections and profile stacks for ocean and weather data, and a grid editor changes model grids cell by cell.

### See and steer running work
The run card says what each step was given, shows each step's question and opens its conversation. Stop asks before stopping work the conversation started. A flow a Python script started shows its run under the message that started it.

### When something goes wrong
Report a problem sends what happened with the conversation. Failed and interrupted replies say why and how to recover.

### Plugins
The plugin list picker, a Plugin list context category and plugin search rows make it easier to add what a conversation needs. Offers say how a plugin joins the turn.

## Fixed
Settings, Memory, infrastructure tabs and decision cards fit at narrow widths and large interface sizes, with whole words and paths that wrap at separators. Switch the interface language from Ctrl K.

## Changed
Desktop counts itself among the clients of a CLIO server it attaches to, so a server a Python script started keeps running while Desktop uses it.
