GACT v0.11.3-beta.8 lets the Desktop update picker recognize beta hotfix releases such as CLIO v0.9.5-beta.5.1.

## Fixed

- Python package versions such as `0.9.5b5.post1` and Desktop versions such as `0.9.5-5+1` display as the same public hotfix version.
- The beta update channel selects a published hotfix with updater manifests. Stable users continue to receive stable releases; drafts and incomplete releases remain excluded.

See the [CHANGELOG](https://github.com/iowarp/gact-tui/blob/v0.11.3-beta.8/CHANGELOG.md) for the complete change history.
