GACT v0.11.3-beta.9 shows progress while the Windows installer prepares the bundled execution runtime.

## Fixed

- Runtime setup forwards each backend preparation stage to the installer details as it happens. Users can distinguish runtime unpacking, Python packages, Node packages and native tools instead of waiting behind one unchanged message.
- Failed preparation retains its saved report and displays the error without leaving a partial installation marked complete.
