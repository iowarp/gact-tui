This release fixes what the 0.9.6 on-screen runs found on Windows, macOS and
Linux.

### Every browser page has its tab
Each page a conversation has opened gets a workbench tab, including pages the
agent opened, links and pages from another window. Tabs show the page's favicon
and shorten their names before collapsing to an icon. Closing a tab leaves the
page open in the Browser list.
([#1145](https://github.com/iowarp/gact-tui/pull/1145),
[#1148](https://github.com/iowarp/gact-tui/pull/1148))

### Clear reasons when the local service can't start
When the local service fails to start, its row and the connect attempt say
"Can't connect" with the service's own message and the fix, instead of showing
Limited. A lite Desktop's first run shows its download and package preparation
under Preparing, with progress.
([#1150](https://github.com/iowarp/gact-tui/pull/1150),
[#1153](https://github.com/iowarp/gact-tui/pull/1153),
[#1154](https://github.com/iowarp/gact-tui/pull/1154))

### Sources
Linking a source from a new conversation no longer creates a second
conversation. Remote files whose names aren't valid local paths show their real
names, and browsing says when items were skipped. Globus and the National Data
Platform show their official wordmarks.
([#1169](https://github.com/iowarp/gact-tui/pull/1169),
[#1166](https://github.com/iowarp/gact-tui/pull/1166),
[#1161](https://github.com/iowarp/gact-tui/pull/1161),
[#1167](https://github.com/iowarp/gact-tui/pull/1167))

## Fixed

- macOS: typed identifiers such as `root` are no longer capitalized or
  autocorrected, and Google Drive "My Drive" links are accepted.
  ([#1160](https://github.com/iowarp/gact-tui/pull/1160))
- macOS: smart dashes and quotes no longer turn `--version` into a dash; an
  unavailable source action clears, and the indexing count moves smoothly.
  ([#1163](https://github.com/iowarp/gact-tui/pull/1163))
- macOS and Linux: quitting, or accepting Move to Applications, stops the
  managed-package installer instead of leaving a second install running.
  ([#1158](https://github.com/iowarp/gact-tui/pull/1158))
- Desktop never runs an older `clio-agent` found on PATH; it prefers the managed
  install and version-checks anything on PATH.
  ([#1151](https://github.com/iowarp/gact-tui/pull/1151))
- A lite Desktop runs its installer on its own agent store, so the first boot
  doesn't repeat the store migrations.
  ([#1152](https://github.com/iowarp/gact-tui/pull/1152))
- A task waiting for permission or for you stays visible instead of folding into
  "Ran 1 task".
  ([#1149](https://github.com/iowarp/gact-tui/pull/1149))

See the [CHANGELOG](https://github.com/iowarp/gact-tui/blob/main/CHANGELOG.md#0122---2026-11-12).
