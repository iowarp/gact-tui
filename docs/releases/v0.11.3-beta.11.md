This beta improves scientific charts, portable conversations and the National
Data Platform workflow. Recorded activity is easier to read at a glance and
inspect in detail.

### Session and Work rails
Open Session for context usage, sources and compact artifact rows with download
actions. Open Work for goals, questions, todos and background activity. Open
Customize to drag section rows and choose which sections appear. Expanded sections
stay open when reordered, and the layout is saved on this device. Background work
retains its controls, history and links to child conversations.
([#590](https://github.com/iowarp/gact-tui/pull/590),
[#665](https://github.com/iowarp/gact-tui/pull/665),
[#669](https://github.com/iowarp/gact-tui/pull/669),
[#670](https://github.com/iowarp/gact-tui/pull/670),
[#671](https://github.com/iowarp/gact-tui/pull/671))

### Forms, files and loading feedback
Choose dates and times in schedules and generated forms, with the relevant time
zone visible. Add details beside questionnaire choices without losing drafts.
Compact file rows show format, transfer progress and conversion state, while
refreshes keep existing content available.
File views use one filename header with compact Versions and Lineage controls;
tables show their row count once.
Generated-form buttons use the same action styles and keyboard focus as CLIO's
own controls.
([#666](https://github.com/iowarp/gact-tui/pull/666),
[#667](https://github.com/iowarp/gact-tui/pull/667),
[#669](https://github.com/iowarp/gact-tui/pull/669))

### Scientific charts and portable maps
Charts fill the available space when opened or resized, including composed
charts. Selection and brush controls remain available. Exported conversations
render their saved map geometry when opened as local HTML files.
([#658](https://github.com/iowarp/gact-tui/pull/658),
[#660](https://github.com/iowarp/gact-tui/pull/660))

### Readable sources and tool results
Adjacent citations share a Sources control with a clickable list. Tool activity
shows the action, requested files and returned results before technical details;
skill loads include their purpose and distinguish supporting references. Thinking
rows follow the same presentation as other activity.
([#661](https://github.com/iowarp/gact-tui/pull/661))

### NDP datasets, Endpoints and streams
Browse expandable dataset entries, reuse cached discovery results and select an
existing SSH profile when connecting an Endpoint. Bounded stream captures retain
their checkpoint so the next capture can continue, and captured data opens in
the shared map and table views. Account permissions still determine which data
and operations are available.
([#657](https://github.com/iowarp/gact-tui/pull/657),
[#659](https://github.com/iowarp/gact-tui/pull/659),
[#661](https://github.com/iowarp/gact-tui/pull/661))

## Fixed

- The welcome screen leaves the layout when the first message arrives, allowing
  the conversation to use its full height.
- Source permissions show the selected resources and requested access.
- One remaining permission request no longer shows redundant navigation.
- Widget hover text no longer exposes internal revision and state counters.
- Retried operations preserve the earlier invocation's recorded failure.
- Collapsed navigation icons share one center line. Opening a session, search
  or another action from the hover preview keeps navigation temporary until pinned.

See the [changelog](https://github.com/iowarp/gact-tui/blob/v0.11.3-beta.11/CHANGELOG.md)
for the complete changes.
