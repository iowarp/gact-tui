This release redesigns the CLIO web and desktop interface around a new default
look, a workbench of tabs and a conversation rail. It also starts faster,
installs faster on Windows and ships a signed macOS app.

### A new look
Notebook is now the default theme in light and dark; the earlier themes remain
as Classic light and Classic dark in Settings > Appearance. The left bar groups
conversations by day and can filter them, and the top bar shows the workspace
and conversation. Permission and question cards, menus, dialogs and toasts share
one design.

### Conversation rail
Open the conversation rail from the top bar to see context use, account usage,
goals, questions, todos, running work and what the conversation produced.
Customize reorders, adds and removes its sections.
([#748](https://github.com/iowarp/gact-tui/pull/748),
[#907](https://github.com/iowarp/gact-tui/pull/907))

### Workbench tabs and viewers
Files, Sources, Artifacts, Activity, Agent, Terminal and Browser open as tabs
beside the conversation. Viewers switch between Render, Source and Lineage with
Ctrl+Shift+V and Ctrl+Shift+L, and Jupyter notebooks open as cells with their
outputs. Activity leads with the timeline of work across subagents again. The
HDF5 viewer uses the app's colors and keeps its place when the workbench is
maximized.

### Composer and conversations
Press Ctrl+S to put a draft aside and Up in an empty composer to bring it back.
Reference an object inside an HDF5 file with `@file.h5::/path`; references stay
where you typed them in the sent message. When a send fails, the text stays in
the composer with a plain reason and Retry. You can move a conversation to
another workspace when the agent supports it, or export it as HTML or a ZIP of
its artifacts.

### Notifications and runs
The bell lists each pending request with Allow and Deny in place, runs that
ended while you were away (with Retry for stopped ones) and Mark all read. On
desktop, notifications are on by default and open their conversation when
clicked; on macOS they use the system notification settings and a Dock badge.
Runs and Infrastructure open from the CLIO menu.
([#736](https://github.com/iowarp/gact-tui/pull/736),

### Settings and providers
Settings opens as a window grouped into App, Workspace and Agent, and closes
with Esc. Models, Providers, Tools, MCP servers, Extensions and Agents use one
row and detail layout. Provider installs keep running when you switch views, and
a completed GitHub Copilot sign-in waits until the agent reports it ready.
([#750](https://github.com/iowarp/gact-tui/pull/750),
[#755](https://github.com/iowarp/gact-tui/pull/755),

### New providers and attention heat
GitHub Copilot and Inception Mercury are available as model providers, and
diffusion models draw their answer as it forms. Attention heat can be painted by
line, word or token, and you can choose the model SPOTTER runs on.
([#715](https://github.com/iowarp/gact-tui/pull/715),
[#722](https://github.com/iowarp/gact-tui/pull/722),

### Keyboard and accessibility
Cut-off text can be read in full on hover or keyboard focus. Holding Ctrl or Cmd
shows the keys for each control, the shortcut sheet can be searched, and
dialogs, pickers and tabs keep keyboard focus. Secondary text in the light theme
and red menu text in the dark theme now meet a 4.5:1 contrast ratio.

### Speed
The app loads about a quarter of its previous JavaScript at startup. Long
conversations open at the newest messages and load older ones as you scroll,
and streaming replies no longer stall the page. Finding a model in a large
catalog stays responsive, and pages ask the agent for updates less often while
idle.

### macOS
The macOS app is signed with a Developer ID, notarized and requires macOS 15 or
later. It has a native menu bar and Mac shortcuts. Closing the window keeps CLIO
running in the Dock; Quit asks first only while a conversation is running.
([#740](https://github.com/iowarp/gact-tui/pull/740),

### Activity rows read the same way
Tool calls, thoughts and updates such as Memory and Session facts share one row
layout: the name, then its input, then the outcome. On a narrow window the name
keeps its place and outcome words such as "failed" or "stopped" stay whole.
Memory updates show as formatted text, and every stopped call says "Stopped"
with the same explanation. An inline PDF or image opens in a single frame with a
one-row header, and a PDF fits the width of the conversation.
([#1107](https://github.com/iowarp/gact-tui/pull/1107),
[#1109](https://github.com/iowarp/gact-tui/pull/1109),

### Windows installation
The Windows setup no longer carries the runtime. It unpacks the runtime archive
while the installer downloads it, writes the files with four parallel tar
processes and checks the archive's hash before using it. The setup shrinks from
about 780 MB to 43 MB, and in our measurements a cold desktop install with CLIO
finished in under a minute, download included, instead of nearly four.
([#1044](https://github.com/iowarp/gact-tui/pull/1044),
[#1062](https://github.com/iowarp/gact-tui/pull/1062),
[#1072](https://github.com/iowarp/gact-tui/pull/1072),
[#1087](https://github.com/iowarp/gact-tui/pull/1087))

## Since the beta

- Everything between two updates in a conversation folds into one row, so the
  answer is no longer preceded by loose session facts, short thoughts or lone
  tool calls.
  ([#1131](https://github.com/iowarp/gact-tui/pull/1131))
- Office files open straight into their rendered preview, with Export to PDF
  next to Download.
  ([#1122](https://github.com/iowarp/gact-tui/pull/1122),
  [#1124](https://github.com/iowarp/gact-tui/pull/1124))
- The ask to turn on notifications lives in the bell instead of covering the
  start of the answer.
  ([#1121](https://github.com/iowarp/gact-tui/pull/1121))
- Windows Desktop no longer hangs and crashes after start: the agent now gets
  plain Windows paths. The first launch also skips a repeated package check.
  ([#1129](https://github.com/iowarp/gact-tui/pull/1129),
  [#1130](https://github.com/iowarp/gact-tui/pull/1130))
- A beta lite Desktop installs its own beta agent, and the Linux lite AppImage
  installs and finds its agent.
  ([#1126](https://github.com/iowarp/gact-tui/pull/1126),
  [#1123](https://github.com/iowarp/gact-tui/pull/1123))

## Fixed

- Enter selects the highlighted model in the model picker.
- The macOS keychain prompt no longer returns after each Allow.
- macOS startup no longer flashes white or flickers before the startup screen.
- Signing in through the browser no longer fails when the browser is slow to
  send its request.
- Long conversations no longer open blank or lose their newest turns after
  older messages load.
- "Update ready" no longer appears for a failed update check. Update checks wait
  for GitHub's rate limit to reset and say when they can run again.
- Settings sections and the new conversation screen recover after the agent
  restarts.
- A flow that ended before its first checkpoint shows as ended, and a parallel
  group says how many of its calls run at once.
- Tokens left in browser storage by releases from May to August 2026 are
  removed when the app starts.
- Jump to latest lands in one tap and keeps following a streaming reply.
- Pages that failed to load while the agent was unreachable load again once it
  is back, and the app says Connecting rather than Offline before a connection
  has actually failed.
- An inline PDF opens on the page it cites.
- Task rows in the rail show the task title and open its subagent.
- An interrupted tool call no longer shows a raw "null" result.
- Numbered lists show two- and three-digit numbers in full.

## Removed

- The conversation Gantt view, the bottom status strip and the starter prompts
  on a new conversation.
- Releases no longer include the legacy terminal UI binaries or container image.
