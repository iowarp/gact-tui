This beta brings the integrated conversation, document and Settings improvements onto main. It also fixes the web container build and requires main-based tags and curated notes for future releases.

### Conversation activity

Reasoning, progress updates and tool results stay in their recorded order, with compact rows that open the full details. Message footers show available usage, and provider or model changes mark where a new segment begins. (#547)

### Documents and context

Word and PowerPoint outputs keep their PDF review previews attached to the editable document. File previews share download, open, information and fullscreen controls. Optional context and work panels use available space beside the conversation and dismiss when opened as narrow-window flyouts. (#544, #546, #547)

### Settings and readability

New-session defaults use the conversation's provider and model picker. Settings controls share spacing and alignment, reasoning-effort saves finish when acknowledged, and larger-display sizing makes the interface easier to read. Composer contrast and transcript navigation are improved. (#545, #547, #548)

## Fixed

- Web container builds now retain the Globus and Google Drive images imported by the production UI.
- Release preparation is integrated into main before tagging. Future release builds reject feature-branch tags and missing curated notes.

This release supersedes v0.11.3-beta.6, which was published before its develop-to-main integration was completed.
